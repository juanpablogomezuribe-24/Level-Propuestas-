¿Qué debes tener presente si vas a dictar un curso?

1. Compuesto por bloques

Los contenidos estarán divididos por bloques temáticos, organizados de forma progresiva. Cada bloque desarrolla una idea principal y debe poder entenderse de manera clara.

2. Duración de cada bloque

De 1:40 a 2:30 minutos. Sea concreto, directo y evite extenderse en explicaciones innecesarias.

3. Extensión del contenido

El contenido de cada bloque se construye a partir de un texto base de 200 a 300 palabras, que sirve como guía para la explicación del tema.

4. Enfoque pedagógico

Lenguaje claro, pedagógico y aplicado. La idea no es hacer clases largas, sino explicar conceptos de forma sencilla con ejemplos aplicables.

5. Estructura clara y ordenada

Cada curso debe contar con:

  • Un título general del curso.
  • Bloques claramente definidos.
  • Cada bloque debe tener un inicio y un final que conecte con el bloque anterior y con el bloque siguiente.

6. Referencias Visuales

Es responsabilidad del profesor entregar el contenido a nivel conceptual de los gráficos que acompañarán cada bloque. Level se encarga de producirlos.
